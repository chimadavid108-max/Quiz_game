# Quiz Game
 
**A simple mathematics quiz game that lets players answer questions and saves their scores for future sessions.**
 
## Features 
 
- *Math questions*
 
- *Score tracking*
 
- *Automatic score saving*
 
- *Easy to play*

## How to Run
 ```
    python quiz_game.py
 ```
